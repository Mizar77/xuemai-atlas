# 顶会获奖论文作者反向审计

核验日期：2026-08-31

这一轮不从学校院系名录出发，而是从近三年顶级 AI 会议的官方论文奖项出发，反向检查获奖论文作者中的现任教师或独立 PI 是否已在学脉 Atlas 中。

## 时间和奖项范围

- ICLR、ICML、CVPR、ACL：2024–2026。
- NeurIPS：2023–2025；2026 年大会在本轮核验时尚未举行。
- 纳入 Best Paper、Outstanding Paper、Honorable Mention、Best Student Paper、Best Resource / Dataset & Benchmark 等官方论文奖项。
- 共逐篇核验 109 条官方获奖记录：ICLR 25、ICML 27、NeurIPS 18、CVPR 22、ACL 17。

## 纳入口径

- 只新增已由官方院系页、教师页或本人主页确认的现任教师、可独立招生 PI 或独立研究机构负责人。
- 学生、博后、普通产业研究员不会因为出现在获奖作者表中而自动成为导师节点。
- 论文合著不等于师承或长期合作；本轮不从共同署名自动连边。
- 与既有名录或其他会议重复的教师合并为一个节点，只增加获奖论文事实和来源。
- 当前六个地区之外的教师保留在审计报告中，不误分配到现有地区。

## 结果

在跨会议、跨年份和既有名录去重后，本轮新增 91 位现任教师或独立 PI。其中，来自已覆盖重点学校的人物继续放在原学校；来自其他学校的人物按地区放入“获奖作者网络”，人物卡片仍显示真实学校。

此次审计证明：原名录对重点学校的覆盖较好，但对 UCI、Northeastern、Notre Dame、UCF、Augsburg、Caltech、Ohio State、Purdue 等非首批重点机构的获奖论文导师漏召更明显。这些缺口已通过反向审计补入。
